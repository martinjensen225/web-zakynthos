## Session init checklist

For unfamiliar repos or support-file setup only:

1. Resolve the repo root; confirm with `git rev-parse --show-toplevel` when available.
2. Read `CONTINUITY.md` if present.
3. Read `FILES.md` only before support-doc changes.
4. Read `continuity/LEDGER_RULES.md` only before ledger creation or material updates.
5. Create files from `templates/` only when needed.
